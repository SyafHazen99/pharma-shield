## 📌 Project Overview

**PharmaShield AI** is an enterprise healthcare AI platform engineered to secure hospital pharmaceutical supply chains, streamline multi-depo inventory management, and prevent procurement fraud across hospital departments.

### 🌟 Key Pillars & Features

1. **Zero-Trust OCR Vision Scanning**: Hardware-level receipt inspection eliminating phantom billing and invoice discrepancies.
2. **Automated 3-Way Match Verification**: Seamless reconciliation between Purchase Orders (PO), Goods Receipts (GR), and Vendor Invoices.
3. **FEFO (First-Expired, First-Out) Inventory Intelligence**: Real-time algorithmic stock routing across 5 hospital departments (Gudang Central, Rawat Inap, Rawat Jalan, Kamar Operasi, and Ruang Bayi).
4. **Official Vendor Directory**: Pre-verified integration with official hospital distributors (*PT Firdaus Medika Malang, PT Kebayoran Pharma, PT Mitra Farma Anugerah Lestari, PT Satoria Distribusi Lestari, PT Sinar Panca Medika, PT United Dico Citas*).
5. **SATUSEHAT & Webhook Interoperability**: Real-time WIB audit trails and automated spreadsheet synchronization.

## 🛠️ Quick Start

### 1. Installation
```bash
npm install
```

### 2. Run Development Server & Backend API
```bash
# Terminal 1: Start Express API Server
node server/index.js

# Terminal 2: Start Vite Dev Server
npm run dev
```

### 3. Production Build
```bash
npm run build
```
